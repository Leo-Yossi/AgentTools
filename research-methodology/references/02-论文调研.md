# 02 · 论文调研（通用科研全领域）

> 目标：回答"**这个方向别人做到什么程度了**"以及"**有哪些高质量信息源**"。
> 组织方式：预印本 → 检索/索引数据库 → 全文出版库 → 引文网络工具 → 顶会顶刊 → 评价体系 → 检索语法 → 订阅追踪。

---

## 0. 四类信息源的定位差异

| 类型 | 代表 | 时效 | 质量把关 | 用途 |
| --- | --- | --- | --- | --- |
| **预印本** | arXiv、bioRxiv、ChinaXiv | 最快（0～7 天） | 无同行评审（仅初步审核） | 追最新进展、抢首发、看趋势 |
| **索引数据库** | Google Scholar、Scopus、WoS | 快 | 只做收录不做评审 | 检索、统计、引文分析 |
| **同行评审出版物** | 顶会、顶刊、出版社全文库 | 慢（3～12 个月） | 有评审 | 引用、作为可靠依据、技术选型 |
| **引文网络工具** | Research Rabbit、Connected Papers | 依赖上游 | 无 | 发现遗漏、看清技术脉络 |

> **原则**：调研时用预印本看"最新到哪了"，用顶会顶刊看"什么被认可了"，用引文网络看"脉络和遗漏"。三者缺一不可，只查一个会系统性偏误。

### 1.3 预印本的"坑"

- ⚠️ **未经同行评审**，结论可能被撤稿或大幅修改，重要决策不要只依赖预印本。
- ⚠️ 存在"预印本灌水"，同一团队多版本重复发布，注意看版本号（arXiv 的 v1/v2/v3）。
- ✅ 应对：关键结论交叉验证——同一工作是否已被顶会/顶刊接收（可在 DBLP、Google Scholar 查"期刊/会议版本"）。

## 6. 高级检索语法速查 ⭐⭐

### 6.1 通用布尔与通配符
```
"exact phrase"        # 精确匹配
AND / OR / NOT        # 布尔运算（注意必须大写）
(term1 OR term2) AND term3
term*                 # 截词（不同平台符号不同，WoS 用 *，Scholar 不支持通配）
NEAR / ADJ            # 邻近检索（WoS/Dialog 支持）
```

### 6.2 Google Scholar
```
author:"姓氏 名"                     # 限定作者
source:"期刊或会议名"                 # 限定来源
intitle:关键词                        # 标题检索
"关键词" after:2023                   # 时间限定
"关键词" before:2020
filetype:pdf                          # 只找 PDF
"关键词" -review                      # 排除综述
related:url                           # 找相似文献
```

### 6.3 arXiv
```
官网：https://arxiv.org/list/cs.AI/recent
高级检索：https://arxiv.org/a（作者）、https://arxiv.org/search/?searchtype=all
字段：ti:"..."  abs:"..."  au:"..."  cat:cs.CV  AND/OR/ANDNOT
例：ti:"diffusion" AND abs:"medical" AND cat:cs.CV
API：http://export.arxiv.org/api/query?search_query=all:...&max_results=100
```

### 6.4 Semantic Scholar / OpenAlex（可脚本化）
```
Semantic Scholar API: https://api.semanticscholar.org/graph/v1/paper/search?query=...&fields=title,year,citationCount
OpenAlex API:         https://api.openalex.org/works?filter=title.search:...,from_publication_date:2023-01-01
```
> 适合批量拉取某个方向的论文元数据，做引文统计、年度趋势、作者网络分析。

### 6.5 中文库
```
CNKI：SU=主题  TI=题名  KY=关键词  AU=作者  FT=全文  AF=机构
      例：SU=('大模型'+'医疗') AND FT='评测'
      支持"结果中检索"逐层收敛
万方：主题:(A 或 B) 与 作者:(C)
```

### 6.6 检索式构造套路
1. 拆词：核心概念 A（如"联邦学习"）× 场景 B（如"医疗影像"）× 方法 C（如"差分隐私"）
2. 同义词扩展：每个概念列 3～5 个同义/上下位词，用 OR 连接
3. 组合：`(A1 OR A2 OR A3) AND (B1 OR B2) AND (C1 OR C2)`
4. 收敛：先用最严格的组合（三概念 AND）拿核心集，再逐步放宽补召回
5. 去噪：排除 `review / survey`（除非就是在找综述）、排除明显无关学科类别

## 8. 论文筛选分级标准（快速去噪）

拿到一批论文后按以下顺序处理，避免"读了 50 篇还是没结论"：

| 级别 | 判定标准 | 处理方式 |
| --- | --- | --- |
| **P0 必读** | 领域奠基工作 / 近 2 年顶会最佳论文 / 高引（>500）综述 | 精读全文 + 复现要点 |
| **P1 泛读** | 顶会顶刊相关工作、被引 50-500 | 读摘要+图表+结论 |
| **P2 扫读** | 一般会议/期刊，方法相近 | 只读摘要和贡献点 |
| **P3 归档** | 弱相关或质量存疑 | 只记录标题与一句话理由，备查 |
| **剔除** | 非同行评审且结论激进 / 明显水会 / 无法获取全文 | 记录剔除理由 |

**降噪信号**：
- ✅ 有公开代码与数据集 → 可信度 +1
- ✅ 被 Papers with Code 收录并有榜单结果 → 可信度 +1
- ⚠️ 仅预印本、无代码、无对比实验 → 谨慎引用
- ⚠️ 引用量突然暴涨但作者自引集中 → 存疑

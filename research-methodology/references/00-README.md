# 科研调研资源库 · 总纲

> 定位：**通用科研全领域**的调研资源索引 + 可复用的调研执行流程（SOP）。
> 目标：当你接到一个陌生课题时，能在这套文档里直接找到"去哪找数据、去哪找论文、去哪看落地现状"，并按 SOP 走完一遍完整调研，而不是每次从零开始摸索。

**建议阅读顺序**：
1. `05-搜索方法` —— 把脑子里的一段话拆成结构化关键词和检索式（**入口**）

3. `02`（论文）+ `01`（数据）—— 按流程分头执行

> python assets/build_query.py "肺结节|pulmonary nodule" "良恶性|malignancy" --md
> ```

## 二、通用约定

### 2.1 资源条目字段

每一条资源尽量记录以下字段（文档中按信息密度取舍，不强制全填）：

| 字段 | 含义 |
| --- | --- |
| **入口** | 官方网址 |
| **覆盖** | 该源主要收录什么内容 / 什么学科 |
| **许可/费用** | 开放获取 / 需注册 / 机构订阅 / 商用需授权 |
| **适用环节** | 对应 SOP 的哪一步（扫盲 / 检索 / 筛选 / 追踪 / 落地判断） |
| **备注** | 使用门槛、坑点、是否需要科学上网、是否有 API |

### 2.2 图例标记

| 标记 | 含义 |
| --- | --- |
| ⭐⭐⭐ | 高频核心源，任何课题都建议先查 |
| ⭐⭐ | 重要补充源，按学科选查 |
| ⭐ | 特定场景才用 |
| 🇨🇳 | 国内平台，中文界面 / 国内节点，访问友好 |
| 🌐 | 境外平台 |
| 🔒 | 需要机构订阅、账号申请或付费 |
| 🆓 | 免费开放，无需订阅 |
| 🤖 | 提供公开 API，可脚本化批量获取 |
| ⚠️ | 存在合规风险或数据质量风险，需注意 |

### 2.3 维护约定

- **新增资源**时，同步填写"最后核对时间"，链接容易失效，建议每季度抽一批复查。
- **学科深度内容**（如某细分方向的数据集清单）不放主文档，另建 `topics/` 子目录，避免主文档膨胀。
- **现有领域纵深样例**：[`topics/架空线驱鸟监测.md`](./topics/架空线驱鸟监测.md) —— 完整演示"05 搜索方法 + 04-SOP"如何套到一个具体方向（含实跑生成的检索式与链接表、可迁移数据集清单、监测方案选型），可直接复制改关键词复用。
- **失效链接**不要直接删除，改为标注 `~~已失效~~` 并注明替代源，保留排查线索。

```
接到一个新课题
   │
   ├─ 只有一段模糊想法、不知道该搜什么 ─► 05-搜索方法 → 意图解析 → 关键词 → 检索式（★ 先走这步）
   │
   ├─ 有关键词但搜不准（太多/太少/跑偏）─► 05-搜索方法 §8 迭代闭环 → 诊断信号 + 修正策略
   │
   ├─ 完全陌生、不知道领域术语 ──────────► 02-论文调研 → 综述/百科/顶会 Tutorial
   │
   ├─ 想找"别人做到什么程度" ────────────► 02-论文调研 → arXiv + Semantic Scholar + Research Rabbit
   │
   ├─ 想找"能跑的实验数据" ──────────────► 01-数据集调研 → 综合聚合平台 → 学科专题库
   │
   ├─ 想找"产业界落地到哪一步" ──────────► 03-线下渠道调研 → 展会 + 竞赛榜单 + 企业开放平台
   │
   └─ 想形成可交付的结论 ────────────────► 04-调研工作流SOP → 按阶段执行 + 套用模板
```

## 四、使用原则（避免常见坑）

1. **先广后深**：先用聚合检索（Google Dataset Search / Semantic Scholar）确认"有没有"，再进垂直库深挖"好不好"。
2. **先论文后数据**：多数数据集是从论文里长出来的，顺着论文的 Dataset 章节找数据，比直接搜数据平台更准。
3. **许可优先于规模**：数据集再大，许可不允许商用也是白搭。动手下载前先确认 License。
4. **区分"有数据"和"有可用数据"**：很多政务/机构数据名义开放，实际需申请、格式混乱、更新滞后，需实地验证。
5. **论文看引用网络，不看单篇**：单例论文可能是特例，用引文网络（Research Rabbit / Litmaps）看聚类才知道主流路线。
6. **线下信息补充"网上查不到"的部分**：竞赛榜单、展会Demo、企业技术博客往往比论文更早暴露真实水位。

## 六、配套工具

| 脚本 | 用途 | 用法 |
| --- | --- | --- |
| `assets/check_links.py` | 批量校验 md 中的外链可达性 | `python check_links.py 01-...md 02-...md` |
| `assets/build_query.py` | 关键词 → 各平台检索 URL（平台清单来自 `platforms.json`） | `python build_query.py "概念A\|同义A2" "概念B" --md` |
| `assets/platforms.json` | 检索平台数据源：增删 / 修改检索平台只改这里，无需动脚本 | 编辑 JSON 后重跑 `build_query.py` 即可生效 |
| `assets/platforms.user.json` | 个人配置（可选）：自动合并到主配置之上，且不会被主配置更新覆盖；存放你调研中收藏的好源 | `build_query.py --add "名称" --url "..." [--user]` 自动写入 |
| `assets/platforms.user.example.json` | 个人配置模板，复制为上面的文件名后按需改 | — |

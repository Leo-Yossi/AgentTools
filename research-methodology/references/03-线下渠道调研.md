# 03 · 线下渠道调研（展会 · 竞赛 · 会议 · 产业活动）

> 目标：回答"**这个方向做成了什么样、真实水位在哪、能拿到什么资源**"。
> 论文和数据回答"学术上做到哪"，线下渠道回答"**能不能用、谁在做、做到什么产品化程度、有什么可拿的资源（赛题/数据/算力/合作）**"。

---

## 0. 线下渠道的独特价值

| 线上查不到的信息 | 线下能获得 |
| --- | --- |
| 真实产品成熟度与演示效果 | 现场 Demo、可交互体验 |
| 企业技术路线与投入方向 | 技术展台、工程师交流 |
| 未公开的行业数据集/场景 | 竞赛赛题数据、企业开放场景 |
| 人才与合作机会 | 高校展区、招聘、联合实验室 |
| 政策与资金导向 | 政府展区、产业基金、扶持政策 |
| 竞品与同行水位 | 同类展商/参赛队伍方案对比 |

**判断标准**：如果你的课题目标是"落地"或"找资源"，线下渠道的优先级不低于论文调研；如果目标是纯学术前沿，则线下只需关注学术会议。

### 3.4 竞赛的价值与用法

- **拿数据**：多数竞赛赛后开放数据集（天池、DataFountain、Kaggle 均可下载），且是**真实业务数据**，比学术公开数据集更贴近落地。
- **拿方案**：Kaggle 赛后 Top 方案会公开 Notebook / 答辩 PPT；天池/DataFountain 有答辩视频与技术文档。这是"别人怎么做的"最直接的参考。
- **拿算力**：百度 AI Studio、天池实验室、和鲸提供免费 GPU 资源。
- **判断水位**：看榜单分数分布、Top 方案用了什么方法，能直接读出该任务"当前可行解"的上限。

## 7. 线下调研执行清单

**出发前**
- [ ] 明确本次目标（看技术水位 / 找数据 / 找合作 / 找人才 / 找赛题）
- [ ] 列出必看展商/场次清单，预约重点对象
- [ ] 准备 30 秒自我介绍 + 1 页技术方案简介
- [ ] 准备标准问题清单（见下）

**现场**
- [ ] 记录：产品成熟度（概念/样机/量产）、技术路线、是否开放数据/API
- [ ] 收集：名片、技术手册、Demo 二维码、白皮书
- [ ] 拍照/录像需先确认是否允许

**标准问题清单**
1. 这套方案目前是概念验证、试点还是规模化落地？
2. 真实场景下的指标是多少？（实验室指标 vs 线上指标）
3. 数据和模型是自建还是采购？是否开放？
4. 最大的技术瓶颈是什么？
